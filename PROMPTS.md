# AI Summary Prompt

```txt
Analyze this AI tool spend audit for a startup team.

Current monthly spend: ${totalSpend}
Potential monthly savings: ${monthlySavings}
Potential annual savings: ${annualSavings}
Recommendations: ${recommendations}

Generate a concise executive summary explaining:
- Where overspending is happening
- Which optimizations make the most sense
- Why the recommendations are financially efficient

Limit the response to 80-120 words.
```

---

# Why I Wrote It This Way

I intentionally structured the prompt with:

* explicit financial context
* structured recommendation data
* clear response length constraints

This improved consistency and reduced hallucinations.

---

# Failed Prompt Attempts

Earlier prompts were too vague and produced:

* generic startup advice
* repetitive summaries
* incorrect pricing assumptions

Adding structured numerical context improved output quality significantly.
